# PGN Spy v1.2.0

PGN Spy is a Windows desktop application for analyzing chess games in PGN format with a UCI-compatible engine. It helps inspect engine correlation, move quality, and related statistics across a single game or a large collection.

## Highlights

- Windows 11-ready build with updated manifest and DPI-aware UI behavior
- compatibility with modern Stockfish 18 and current UCI handshake behavior
- bilingual English/Russian interface with persisted language selection
- pause, resume, and stop controls during analysis
- automatic saving of XML results and annotated PGN output
- cleaner analysis progress window and improved results workflow

## Package Contents

The Windows release archive includes:

- `PGN Spy.exe`
- `uci-analyser.exe`
- `pgn-extract.exe`
- `README.md`
- `README.ru.md`
- `ReadMe.txt`

## Notes

- A UCI engine is required but is not bundled in the base release package.
- Stockfish 18 is recommended and tested with this version.
- Final XML and annotated PGN files are saved next to the source PGN.

## Quick Start

1. Extract the zip archive.
2. Run `PGN Spy.exe`.
3. Select a PGN file and a UCI engine.
4. Start the analysis and review the resulting XML or annotated PGN.
